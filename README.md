# Mogg — приложение для луксмаксинга (Android)

Индивидуальная программа для лица, кардио и питания. Всё хранится на телефоне, без облака.

## Что внутри
- **Анализ лица** — ML Kit сам расставляет точки на фото и считает симметрию, кантальный наклон, «ленивый глаз», пропорции челюсти и лица. Плюс анкета для того, что по фото не видно.
- **Утро до 10 мин / вечер до 20 мин** — программа собирается под твои недостатки и меняется день ото дня. Между упражнениями отдых 10 секунд, чтобы переставить пальцы.
- **Экран тренировки**: сверху — последнее видео MrBeast (официальный плеер YouTube), снизу — видео техники упражнения. Голос объясняет, как делать, а видео сверху на это время приглушается.
- **Кардио**: беговая дорожка (скорость/наклон) или обычное кардио (ходьба, велосипед, эллипс). Видео почти на весь экран, в углу — режим и таймер.
- **Питание**: цель по калориям, кардио подстраивается, чтобы «чистыми» оставалось около 1000 ккал, но без опасного дефицита. Синхронизация с **YAZIO** через Health Connect.
- **Гайды**: лицо, глаза, брови, кожа, сон, мьюинг, осанка, фрейм, сушка.
- **Напоминания** утром, днём (кардио) и вечером + **виджет** на рабочий стол.

## Как получить APK
GitHub → вкладка **Actions** → последний запуск **Build APK** → внизу **Artifacts → Mogg-apk**. Скачай, распакуй zip и установи `app-release.apk` (разреши установку из неизвестных источников).

Локально: `./gradlew assembleRelease` (нужен Android SDK).

## Озвучка ElevenLabs
```
export ELEVENLABS_API_KEY=...
python3 tools/generate_voice.py
```
mp3 появятся в `app/src/main/assets/voice/`, и приложение будет использовать их вместо встроенного голоса Android. Ключ в репозиторий и в APK не попадает.

## Упражнения
Список — в `app/src/main/assets/exercises.json`: видео, отрезок (секунды начала и конца), длительность, текст для голоса, шаги и теги недостатков. Добавил упражнение в JSON → оно автоматически попадает в подбор программы.
